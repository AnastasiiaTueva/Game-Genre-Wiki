GameGenreWiki is a personal full-stack web development project focused on building a game genre encyclopedia.
The project started as a front-end HTML/CSS practice website and is gradually evolving into a fully functional web application featuring:

Responsive user interface
User registration and authentication
Database integration
Genre and game information pages
Search and filtering functionality
User profiles and personalization
Future content management features

The primary goal of this project is to gain practical experience with modern web development technologies. This repository serves as a long-term learning project and will continue to evolve as new features are implemented.
